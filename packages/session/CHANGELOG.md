# @pracht/session

## 0.2.0

### Minor Changes

- [#493](https://github.com/JoviDeCroock/pracht/pull/493) [`32c952d`](https://github.com/JoviDeCroock/pracht/commit/32c952d914f8105fcbd97b4b1321893683c16d55) Thanks [@JoviDeCroock](https://github.com/JoviDeCroock)! - Add `absoluteMaxAge` to `createSessionStorage()`: a cap in seconds on a session's total lifetime that rolling re-commits cannot extend.

### Patch Changes

- [#485](https://github.com/JoviDeCroock/pracht/pull/485) [`aef4ef6`](https://github.com/JoviDeCroock/pracht/commit/aef4ef6cb9f70df2f2b2a51122e4fe7e66dfc88e) Thanks [@JoviDeCroock](https://github.com/JoviDeCroock)! - `@pracht/vite-plugin`, the adapters, `@pracht/session`, `@pracht/i18n`, `@pracht/query`, and `@pracht/test` now take `@pracht/core` as a peer dependency, so upgrading core no longer installs a second copy under them.

- [#513](https://github.com/JoviDeCroock/pracht/pull/513) [`2671f7c`](https://github.com/JoviDeCroock/pracht/commit/2671f7c2d58574ac2e38230721268fdaa790d6d8) Thanks [@JoviDeCroock](https://github.com/JoviDeCroock)! - The published JavaScript no longer carries doc comments, which shrinks an app's server bundle by about a third.

- [#464](https://github.com/JoviDeCroock/pracht/pull/464) [`fb53c1d`](https://github.com/JoviDeCroock/pracht/commit/fb53c1d31436853408fdf008844430a8324e89df) Thanks [@JoviDeCroock](https://github.com/JoviDeCroock)! - Under a deploy base, `requireSession` now puts the route path without the base in `?redirect=`, so a login handler that passes it to `redirect()` returns the visitor to the page they asked for instead of `/base/base/…`.
